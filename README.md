# GreenLeaf Restaurant Website

A modern, responsive website for a plant-based vegan restaurant located in Wapping Wharf, Bristol. Created as a university Graphic & Web Design assignment.

## Live Demo
[View the live website](https://t2-khatri.github.io/GreenLeafRestaurant/)

## Features
- Fully responsive design (mobile-first)
- Bootstrap 5 framework
- jQuery interactive elements
- Google Maps integration on location page
- Reservation and newsletter forms

## Technologies Used
- HTML5 / CSS3
- Bootstrap 5
- jQuery
- Google Fonts (Libre Baskerville + Inter)

## Pages
- Homepage with menu grid
- Location page with map and opening hours
